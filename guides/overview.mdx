This section contains task-based guides: how to do a specific thing, step by step, with real requests. If [Core Concepts](/concepts/overview) explains _how everything works_, this section shows _how to use it_.

Guides differ from the [Quickstart](/quickstart) in depth: the quickstart gives you a first taste in five minutes, while each guide covers a single task end to end, including edge cases and checks.

## Prerequisites

All guides use the REST API with a Bearer token:

- Your instance's base URL, shown as `[BASE_URL]` in the examples.
- An access token for the `Authorization` header (see [Authentication](/authentication)).
